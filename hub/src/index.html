WHAT THE SKETCH DOES

Two inputs. Two directions.

Sensor 1 then sensor 2, within 2 seconds, calls the up animation. Sensor 2 then sensor 1 calls the down animation.

Up uses a blue-to-violet hue range. Down uses the sketch’s magenta-to-orange/red hue mapping. Both use a five-LED head and a fading tail.

CURRENT LIMITS

A prototype, preserved.

75 LEDs are allocated; only the first 50 are animated. Each frame delays 25 ms, so sensors are not polled during an animation.

No Wi-Fi implementation or 15-sensor implementation is present in this revision. No extra releases are claimed.

CONFIRMED IN CODE

Digital, active-low inputs.

D2 and D3 use INPUT, not INPUT_PULLUP. The sketch treats LOW as triggered. It does not establish a sensor voltage, output type or external biasing circuit.

The LED type is WS2812B, driven from D6 using FastLED with GRB color order.

NEEDS PHYSICAL VERIFICATION

Photo inventory, now identified.

Project photos identify the Arduino UNO R4 WiFi and four-pin HW-870 reflective IR modules labeled VCC, GND, DO and AO with a blue threshold pot. Gary counts fourteen modules, with two currently connected. DO polarity and AO response direction still need observation.

These pictured modules are close-range TCRT5000-family reflectance sensors, not time-of-flight devices. Six additional three-pin LDR ambient-light threshold modules are a different component. No private project photos are published.

PHOTO LABELS / NOT A POWER-WIRING APPROVAL

LED strip & power inventory

WS2812E bag: 5V, 5m, 90W. YS-0510DC adapter: 5V, 10A, 50W. The labeled full reel requires 90W ÷ 5V = 18A, exceeding the adapter’s 10A rating. Do not route LED current through the UNO or a breadboard.

The original sketch specifies WS2812B; the new bag says WS2812E. Do not assume protocol, connector or wiring compatibility from that label alone. The strip input arrow and connector polarity remain unverified.

Available: a 1000µF / 16V capacitor kit and a visible loose 1000µF / 10V capacitor. Keep capacitors disconnected until wiring and polarity are verified. No capacitor connection instructions are established here.

ADDITIONAL SENSOR / IDENTIFICATION STILL CONDITIONAL

A separate CQRobot ToF carrier.

New front/back photo inspection shows CQRobot branding, generic VL53LX marking and a white six-pin connector, strongly matching the CQRWX00744US VL53L1X carrier. The exact SKU is not printed in the photo. This is distinct from the fourteen HW-870 reflectance modules.

The matched manual documents 3.3V/5V and onboard voltage translation. Wiring and chip identity remain unconfirmed; INT/SHUT tolerance is not assumed. Open the separate ToF bench path →
